# Screenshots

Place application screenshots in this folder once the system is running.

Suggested screenshots to capture:

1. **dashboard.png** — Dashboard page showing stat cards and recent tickets
2. **create-ticket.png** — Create Ticket form
3. **ticket-list.png** — All Tickets page with the filter bar
4. **ticket-detail.png** — Ticket detail page (view mode)
5. **ticket-edit.png** — Ticket detail page (edit mode)
6. **search.png** — Search page with results
7. **api-docs.png** — FastAPI's `/docs` Swagger UI
8. **postman-create.png** — POST /tickets in Postman or curl
9. **postman-list.png** — GET /tickets in Postman or curl
10. **postman-search.png** — GET /search in Postman or curl

To capture screenshots:
- On macOS: `Cmd + Shift + 4`
- On Windows: `Win + Shift + S`
- On Linux: use `gnome-screenshot` or `flameshot`
